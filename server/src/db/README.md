# server/src/db

Database access: node-postgres Pool, Kysely 0.29.6, errno mapping (for example 55P03 to EBUSY), and `types.gen.ts` generated by kysely-codegen (`--verify` in CI).

- **Primary owner:** R2 VFS/DB
- **Secondary reviewer:** R5 QA/DevOps
- **Spec:** [specs/09-database/database.md](../../../specs/09-database/database.md)
- **Requirement IDs:** DB-01, DB-03

Regenerate the types after a migration (CI runs the same command with `--verify`). The pattern also
excludes the `pg_stat_statements` views that migration 1's extension adds to `public`:

```sh
server/node_modules/.bin/kysely-codegen --dialect postgres --url "$DATABASE_URL" \
  --out-file server/src/db/types.gen.ts --exclude-pattern '(schema_migrations|pg_stat_statements*)' \
  --type-mapping '{"int8":"number","date":"string","vector":"string"}'
```
