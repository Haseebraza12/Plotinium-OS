# wm/src/tokens

The single `tokens.css`: light and dark themes, reduced-motion tokens, `--pl-*` custom properties. It styles the boot screen before any JavaScript runs and is seeded to `/system/branding`.

- **Secondary reviewer:** R5 QA/DevOps

- **Requirement IDs:** WM-07, BOOT-13
