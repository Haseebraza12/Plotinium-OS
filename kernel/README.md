# @plotinium/kernel

The kernel: exactly ONE dedicated module worker per origin (Web Lock `plotinium:kernel` plus a fencing epoch in IndexedDB `meta`). It owns the process table, the scheduler (own heap, round-robin, aging), the executor pool and watchdog, the syscall dispatcher and IPC, the memory manager with the LRU pager and swap tiers, and the klog ring (C2).

## Layout

| Folder         | Contents                                                                                                                                                                                                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `src/core/`    | `proc/` (PCB, lifecycle, signals, job control), `sched/` (heap, aging, bands), `mm/` (accounting, pages, reclaim, swap tiers), `ipc/` (dispatcher, capabilities, audit, events, pipes), `hooks/` (no-op AI seams, exported as `@plotinium/kernel/hooks`), `klog/` |
| `src/host/`    | `worker.ts` (kernel worker entry), `main.ts` (main-thread kernel-link router), `loopback.ts` (Node test host)                                                                                                                                                     |
| `src/runtime/` | `executor.ts` (slice loop, SAB control block, global shadowing), `sys.ts` (the sys client, exported as `@plotinium/kernel/sys`)                                                                                                                                   |
| `src/blkio/`   | `blkio.worker.ts` (OPFS swap device) and the IndexedDB `plotinium-swap` fallback                                                                                                                                                                                  |

## Commands

```sh
pnpm --filter @plotinium/kernel typecheck   # this package against its own tsconfig.json
pnpm --filter @plotinium/kernel test        # the Vitest project named "kernel"
```

Test titles MUST begin with the requirement ID, for example `VFS-06 rejects a write beyond quota with EDQUOT and no partial data` (C18).
