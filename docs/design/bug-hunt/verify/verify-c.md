# verify-c: independent verification of fix-apps-settings-a11y and fix-system-services (Wave 3, 2026-09-30)

Scope: the 45 bugs that `BUGS.md` §2 gives to **fix-apps-settings-a11y** (22) and **fix-system-services**
(23), plus a regression hunt in those areas and the extra checks of the verifier brief (axe, services,
Service Worker and offline boot, build id, WebSocket, console, Task Manager and Settings end to end).

**How.** Every live check ran on the QA Docker build at http://localhost:4718 (real Caddy CSP), Chrome
(channel `chrome`), 1440×900 unless noted, with session `state-verify-c.json` (user examiner2), a
`securitypolicyviolation` listener, and console, page-error and failed-request listeners. Guest was used
only for the log-out check. Builds: **6df55c0** (the gate's final build) for the first pass, then
**0872260** after my fixes (I rebuilt only `web` through `qa-compose.sh`; `version.json` and `readyz`
both report 0872260). Judgement is against `BUGS.md` "Expected" / "Done when" and the specs, not against
the fixers' status files.

Evidence paths are relative to `docs/design/wave3/verify-c/`. Every screenshot listed was read. The
Playwright scripts are in the session scratchpad (`vc/*.mjs`), not in the repo. Contrast figures marked
"px" were measured from screenshot pixels at DSF 2 (the in-page estimate is unreliable over glass).

**Headline.** 41 VERIFIED-FIXED (3 of them only after a fix in this pass), 2 STILL-BROKEN as partials
that need work outside these areas (UI-133, UI-162), 1 NOT-REPRODUCIBLE on a single build (UI-136),
1 VERIFIED-FIXED by unit tests with the live check left to the gate's run (UI-036). All runs on both builds:
**0 CSP violations (enforced and report-only), 0 console errors or warnings, 0 failed requests.**

## 3. Regressions and new findings

Fixed in this pass (all in my areas, each with a regression test that fails without the fix):

1. **Task Manager showed duplicate AI processes** (UI-160 regression). Removing the brackets made the kernel
   service record `[ai.indexer]` and the program `ai.indexer` identical ("ai.indexer · background"), and
   the AI tab and Settings pointed at the record (pid 14, 0 B) instead of the working indexer (pid 15).
   Fix: `isServiceRecord()`; records keep the `service` badge; `findProcess` prefers the program.
   Files: `apps/taskmgr/model.ts`, `apps/taskmgr/tests/ui-160-service-record.test.ts`.
2. **Network & Sync contradicted itself** (UI-141 still broken on the Docker build): "Online · Last synced
   never" with the notice "Everything is synced." `lastAckAt` is only set when the server acknowledges an
   op, so a fresh LIVE session has none. Fix: `networkDescription()` in
   `ui/src/apps/settings/panes/GeneralPanes.tsx`; test `ui/src/apps/settings/ui-141-network-status.test.tsx`.
3. **"Sync files: Not available in this build"** was false after UI-006 (files do sync). Fix: the note in
   `ui/src/apps/settings/availability.ts`; `ui/src/apps/settings/polish.test.tsx` updated.

Checked and fine: the macOS look in both themes and at 1280×800 (`small-1280-*.png`), reduced motion
(Task Manager dark + `reducedMotion: reduce`), keyboard (Renice popover, Settings sidebar, slider arrows),
Settings accents, CSP (0 everywhere), the Service Worker, offline boot, one build id on all tiers, the
live WebSocket, and all 18 services running (sync, lockd, ai.agent and update included) on both builds.

Not bugs: the aging bound's "N = 51" is the spec's declared starvation bound (processes-and-scheduling.md
PROC-04), not a live count; disabled checked Pin switches use the faded-accent disabled style; the axe
`target-size` hits on traffic lights occur only where another window covers them.

Seen in other owners' areas (handoffs, not changed):

- **Login screen, axe serious `aria-prohibited-attr`** (both themes): the clock's `<time>` carries an
  `aria-label` without a role (`axe.json`, `axe-login-*.png`). Owner fix-boot-login (`ui/src/login/**`):
  keep the spoken form (UI-150) in a visually hidden span and mark the `<time>` `aria-hidden`, or give the
  wrapper `role="group"`/`role="img"` with the label.
- **Editor status bar, axe serious `target-size`** (both themes): the "saved v0" and "Indentation Spaces: 2"
  buttons are 17.4 px tall (WCAG 2.5.8 needs 24×24 or spacing). Owner fix-files-editor
  (`ui/src/apps/editor/EditorStatusBar*`).
- **Semantic search indexes `~/.sh_history`**: `semsearch` returned the shell history as the second hit
  (`sys2-semsearch-light.png`), which leaks typed commands into search results. Owner: AI (`ai/src`
  indexer walk); skip dotfiles or at least `.sh_history`.
- The Terminal status still says "AI unavailable · plain shell" (UI-055, carried by the gate).
