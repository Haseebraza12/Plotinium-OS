## Handoffs

- **fix-system-services**:
  - UI-036: implement `window.setCloseGuard`. The Editor already calls it by name, and `apps/editor/proc.ts` relays it in case its origin is E.
  - UI-112: let an app opt out of restoring a pathless window. For example, `session.current()` could skip `editor` windows whose argv is only the program name, or `window.create` could accept `restore: false`.
  - UI-104: `window.focus` could honour input in another window of the same session within the activation window, so an Editor revealed from Files comes to the front.
