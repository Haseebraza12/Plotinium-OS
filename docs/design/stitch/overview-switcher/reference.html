    # OS Report — Process Scheduling

    Plotinium schedules every app as a process. sched keeps a binary-heap ready queue ordered by priority, so ai.indexer (pid 23, priority 32) never delays terminal or files (priority 16).

    ## Measurements

    With 10 windows dragged and the frame meter on, p95 frame time stayed at 16.7 ms at 60 Hz with 0.4% dropped frames.

    ## Memory

    Budget 256 MB; minimised windows are paged first when use reaches 85%.
