# Report — Process Scheduling

Plotinium runs every app as a process with its own pid. The scheduler sched uses a priority queue with a 10 ms quantum; background services such as ai.indexer (pid 23) run at priority 32 so that interactive windows stay smooth.

## Priority classes

init (pid 1) starts vfs, syncd and sched, then the desktop. Interactive processes (terminal, files) get priority 16. A process that exceeds its memory budget is paged to swap before any window freezes.

## Memory budget

The default budget is 256 MB. At 85% the kernel starts reclaiming; at 95% the meter turns red and minimised windows are paged first.
