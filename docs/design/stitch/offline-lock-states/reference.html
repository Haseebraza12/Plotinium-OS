4## 3. Scheduler
5Plotinium uses a multilevel feedback queue with 64 priority
6levels. Lower numbers run first; aging lifts a waiting
7process by one level every 250 ms.
8
9- init (pid 1) owns the service DAG.
10- ai.indexer (pid 23) runs at priority 32 so it
11 never starves the UI thread.
12- sched, vfs and syncd are kernel services.
13
14## 4. Offline sync
15Every change goes to a durable outbox first, then is
16replayed with idempotency keys: "0 lost, 0 duplicated".
17
18## 5. Distributed locks
19A second writer gets EBUSY or read-only access; a
20crashed holder's lease expires within the TTL (15 s demo).
