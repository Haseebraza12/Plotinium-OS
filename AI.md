## 1. Subsystems chosen

**All three** (C12): **A. semantic VFS search (RAG), built deep**; **B. agentic system execution, built deep**; **C. predictive process pre-fetch, lean but complete.** The spec asks for depth over count; Plotinium builds all three because each is small enough to meet the depth bar when it is a process of the OS rather than a separate service, and because C carries the "informs the system" coupling most directly.

**Descoping rule** (committed before Week 12, [ai-safety-and-evaluation.md §3.13](specs/10-ai/ai-safety-and-evaluation.md)). A subsystem is claimed at the P4 gate only if every cell of its coupling-map row is implemented and tested, its evaluation meets its target, its safety tests pass and it degrades gracefully. Extras are cut in this order: the optional RAG LLM answer, hybrid RRF, the naive-Bayes challenger, `ai undo`, HNSW, WebGPU. C is never dropped.

**Week-12 checkpoint record** — A indexes a file and answers `semsearch`; B takes a plan through validation to a dry run; C predicts and runs a pre-fetch job. Result: _to be filled at Week 12 (date, result per subsystem, owner's signature line)._

### 4.1 The litmus test (spec §3.4)

"Remove your AI module and rebuild … if the scheduler loses its pre-fetch hints, the shell loses natural-language execution and the file system loses semantic search, while everything else keeps working, then your AI is foundational and correctly isolated." **Mechanism:** the kernel exposes three seams with no-op defaults (`SchedulerHints`, `ShellNL`, `FsSemanticSearch` in `kernel/src/core/hooks`); `ai/` registers the real ones at service start. The AI-off build sets `__AI__=false` (tree-shaking the registrations and the `/bin/ai`, `/bin/semsearch`, `/bin/predict` manifests) and the server runs with `AI=0` (no `/api/llm`, `/api/index`, `/api/telemetry`). **The `litmus` CI job** builds both and runs every non-AI e2e test on the AI-off build, asserting that `ai`, `semsearch` and `predict` print `command not found`, that `ps` shows no `ai.*` or `prefetch:*` process, that no request reaches `/models`, `/ort` or the AI routes, and that the bundle contains no ONNX runtime or model. At the P4 gate both builds run side by side (ports 4717 and 4718). **Status:** the seams exist as interfaces; the job is added with the first kernel build.

## 6. Safety controls

**Spec: MUST, §3.4:** "The model is an untrusted user-space process: it proposes, and the kernel decides."

| Principle (§3.4)       | A. RAG                                                                                                   | B. Agent                                                                                                                                                                                                                                                                                                                                            | C. Pre-fetch                                                                          |
| ---------------------- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| **Least privilege**    | indexer and search run as the login uid with capability `ai.index` only; `index.put` needs w on the file | the real login uid (an agent started from a root shell drops privileges); `fs.scope = {cwd, $HOME}`; `batch.grant` only after confirmation, narrowed to the confirmed `(op, ino)` set                                                                                                                                                               | `prefetch:*` holds `mm.speculative` and read-only `fs.read`; a write fails with EPERM |
| **Plan before acting** | n/a (read-only)                                                                                          | the kernel re-parses the plan, resolves every path as the uid, checks capabilities, rwx and quota, applies intent binding, and dry-runs it on a read snapshot, printing the blast radius                                                                                                                                                            | n/a                                                                                   |
| **Confirmation**       | n/a                                                                                                      | one kernel predicate (any delete, overwrite, chmod/chown, or more than 20 inodes); rendered by the kernel on the TTY; default N; the answer is read only from kernel-owned TTY input, so `yes \| ai …` cannot confirm and destructive plans are refused without a TTY (ENOTTY); an HMAC token bound to the plan and dry-run hashes, one-shot, 120 s | n/a                                                                                   |
| **Atomicity**          | `ai.index.put` replaces a file's chunks in one transaction; server chunks cascade inside `vfsTxn`        | one IndexedDB transaction and one server `vfsTxn`, with the dry-run fingerprint re-checked (EAGAIN `stale-plan` if anything changed); `kill` mid-plan rolls both back                                                                                                                                                                               | speculative pages are clean copies                                                    |
| **Content is data**    | chunk text never reaches a tool-using model; output rendered as text nodes                               | the planner **never sees file contents**; names are JSON-escaped (control, bidi, zero-width and tag characters escaped) inside `<untrusted>` blocks marked with a per-request nonce; each step quotes a verbatim span of the request; model output is only parsed as data (no `eval`: the CSP has no `unsafe-eval`)                                 | telemetry holds app ids only                                                          |
| **Auditability**       | syscalls in the trace ring; `index.put` in server logs                                                   | every executed agent syscall has an `audit_log` row in the same transaction, with the prompt, plan, confirmation and outcome; rejected and killed plans are recorded after the rollback; `ai log` works offline                                                                                                                                     | spawns and outcomes in the trace ring and `bootlog`                                   |
| **Graceful absence**   | BM25 fallback with a notice                                                                              | offline, rate-limited, over budget, no key or provider failure → `EAIUNAVAIL` with a clear message; refusal → `EAIREFUSED`; the rest of the OS keeps working                                                                                                                                                                                        | unaffected offline; MFU cold start                                                    |

**Prompt-injection defence in layers** — each INJ-20 technique must be stopped by at least two:

| Layer                           | Mechanism                                                                                                                                                   |
| ------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| L1 No ambient authority         | tools are typed syscalls; model output parsed with Valibot; no `eval`, `Function` or shell-string path exists                                               |
| L2 Content separation           | the planner never receives contents; content predicates return names or counts; values from the tool-less extraction call can only fill name slots          |
| L3 Datamarking                  | per-request nonce on every untrusted line; escaping of control, bidi, zero-width, tag characters and `<` `>`; `suspicious_content_seen` forces confirmation |
| L4 Intent binding               | each step quotes a verbatim span of the user's words; a destructive step needs a licensing verb                                                             |
| L5 Argument grounding           | a path not traceable to the request, a set, an observation or an extraction handle forces confirmation                                                      |
| L6 Kernel validation as the uid | scope roots, rwx, quota and `/system` rules through the same `vfs/perm.ts` as every syscall                                                                 |
| L7 Kernel-decided confirmation  | the predicate over the dry run; kernel-owned TTY; type-ahead flushed; HMAC token; `batch` recomputes the predicate                                          |
| L8 Recoverability               | one transaction, audit, trash for agent deletions, `ai undo`                                                                                                |
| L9 Retrieval safety             | permission filter before ranking; foreign verification; the optional answer call is tool-less and each claim must cite a retrieved chunk                    |

## 7. Cost report

**Spec: MUST, §12.6:** "Log tokens and cost for every request, set a budget cap, and report the total cost of development and the demonstration."

- **Logging.** Every provider call — gateway traffic, evaluation runs, the bake-off, the optional RAG answer — goes through one cost logger and writes one `llm_requests` row (uid, purpose, requested and served model, input, cached, cache-write and output tokens, reserved and settled USD, latency, status). The table exists (migration 6); the gateway route is not wired yet.
- **Budget.** The gateway reserves the estimated cost in a short transaction on `llm_usage`, calls the provider **outside** any transaction, then settles. Caps: US$50 per month and US$250 per semester (alerts at 50/80/100%); per user US$2/day; guests and the public demo account 20 calls/day; examiner accounts US$15/day and 100 calls/day on their own pool; rate limits 6/min and 60/h per uid. Exhaustion returns `EAIUNAVAIL` (`budget` or `rate`). The defence-day preflight fails below US$20 remaining.
- **Local compute** for embeddings and prediction costs no money and is reported as CPU-ms per chunk.
- **Estimate** _(estimate — replaced by measured usage)_: about US$0.047–0.066 per `ai` command on Opus 5.5 with a 4k cached prefix; US$22–33 per month in use; the Week-3 bake-off ≤ US$25.
